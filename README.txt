寶可夢中英圖鑑 V2
====================

新增功能
- 1,025 隻寶可夢繁中 / 英文名稱
- 寶可夢圖片
- 繁中屬性
- 第一～第九世代篩選
- 屬性篩選
- 編號 / 中文 / 英文 / 屬性即時搜尋
- 收藏（儲存在這台 iPhone）
- PWA 離線 App shell
- 「下載離線圖片」：一次快取 1,025 張 sprite，之後斷網仍可看圖

部署
1. 將本 ZIP 解壓縮。
2. 把 index.html、manifest.webmanifest、sw.js、icon.svg 四個檔案部署到同一個 HTTPS 資料夾。
3. iPhone Safari 開啟網址。
4. 分享 → 加入主畫面。
5. 第一次有 Wi‑Fi 時，按「下載離線圖片」，等待顯示完成。
